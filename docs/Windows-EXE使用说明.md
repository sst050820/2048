# 《凝合》Windows 免安装版 使用说明

《凝合》是一款果冻软球合成休闲游戏：把顶部待发的水球弹射入场，相同数字的球碰撞即融合成更大的球，目标是堆出最大的数字。本版本为 **Windows 64 位免安装版**，无需安装 Node.js 或任何运行环境，解压后双击即可离线游玩。

---

## 一、系统要求

- Windows 10 / 11，**64 位（x64）**系统。
- 硬盘空间：约 400 MB（ZIP 约 152 MB，解压后约 380 MB）。
- 无需联网、无需安装任何运行库或开发环境。

## 二、首次启动（务必先完整解压）

1. 拿到 `凝合-1.0.0-win64.zip` 后，**右键 →“全部解压（Extract All）”**（或用 7-Zip、Bandizip 等解压工具），选择一个目标文件夹。
2. 解压后得到一个名为 **`凝合`** 的文件夹，进入它。
3. 双击里面的 **`凝合.exe`** 即可启动游戏。

> **不要直接在压缩软件的预览窗口里双击 `凝合.exe` 运行**——那样程序只被临时解压、可能丢失运行依赖，会出现黑屏或闪退。必须先完整解压到磁盘。

### 关于“Windows 已保护你的电脑”提示

本程序为个人制作、**未购买代码签名证书**，首次运行时 Windows SmartScreen 可能提示“已保护你的电脑”。这是未签名软件的正常现象，不代表有病毒：

- 点击提示窗口中的 **“更多信息”**；
- 再点击 **“仍要运行”** 即可启动。

如个别杀毒软件拦截，可在确认压缩包 SHA-256 与本说明一致后（见文末）将其加入信任。

## 三、玩法操作

- **瞄准与发射**：在游戏区域内**按住鼠标拖动**，顶部待发的水球会沿浮条移动并出现瞄准方向；**松开鼠标**即把水球沿该方向弹射入场。
- **合成规则**：两个**数字相同**的球碰撞后融合为一个数字翻倍的球（1+1→2，2+2→4，以此类推），数字越大球越大。
- **不同数字的球相撞不会融合**，只会互相弹开、堆叠。
- **顶部待发区**：待发的球被压成统一高度的水袋依次排开，宽度随数字变化；把球向上弹、与待发区同数字球融合时，结果仍留在待发队列，不会直接掉进场地。
- **失败条件**：球堆持续长高，越过左右两侧顶部警戒线并持续停留一段时间，本局结束。
- 下一颗待发球为随机数字，已合成到的数字越大，可能出现的待发数字越多。

| --- | --- |
| **F11** | 窗口全屏 / 退出全屏（桌面版专属） |

## 五、存档位置与续玩

- 存档保存在当前 Windows 用户目录下，**与程序所在文件夹无关**：
  ```
  %APPDATA%\Ninghe
  ```
  在文件资源管理器地址栏直接粘贴上面这串路径并回车，即可打开存档目录。
- 下次启动时，标题页会出现 **“继续游戏”**，点击即可回到上次的局面；点 **“新游戏”** 则开一局新的。
- 游戏同时记住窗口大小、全屏状态、主题、静音与成就进度。
- 因为存档在用户目录，**移动或升级游戏文件夹都不会丢失进度**（同一 Windows 用户）。

## 六、如何更新（手动）

本版本**不含自动更新**，需要手动替换：

1. 下载新版本的 `凝合-x.x.x-win64.zip`。
2. **先完全退出当前游戏**（点窗口右上角 X，等待窗口关闭）。
3. 解压新 ZIP，用里面的 **`凝合` 文件夹整体替换**旧的 `凝合` 文件夹（可直接解压覆盖到同一位置）。
4. 双击新文件夹里的 `凝合.exe` 启动。存档在 `%APPDATA%\Ninghe`，升级不受影响。

## 七、移动 / 拷贝注意事项

- 想把游戏放到别的位置或拷贝给朋友时，**请移动或复制整个 `凝合` 文件夹**，不要只单独拖走 `凝合.exe`。
- `凝合.exe` 依赖同目录下的 `resources`（含 `app.asar`）以及大量运行时 DLL / pak 文件，**只移动单独的 exe 会因缺少依赖而无法启动**。
- 整个文件夹是绿色便携的，可放在 U 盘、任意磁盘、任意中文或含空格的路径下运行（但仍建议先完整解压）。

## 八、如何彻底删除

- 删除解压得到的整个 `凝合` 文件夹，即删除了程序本体。
- 若要一并清除存档与设置，删除 `%APPDATA%\Ninghe` 文件夹即可。
- 免安装版不写注册表、不创建开机启动项。

## 九、常见问题

- **双击后短暂黑屏或几秒才出现画面**：首次启动解压资源、初始化字体属正常现象，稍等即可。
- **窗口画面模糊**：本程序支持高分屏缩放。若仍模糊，可在高 DPI 屏幕上右键 `凝合.exe` → 属性 → 兼容性 → 更改高 DPI 设置，勾选“由应用程序缩放”。
- **切换到其他窗口后游戏自动暂停**：这是正常设计，回到窗口后按 P 或点“继续”即可，避免切回瞬间误发射。
- **完全离线也能玩**：所有素材已内置，不联网、不联网验证。
