# 球体突然变圆并卡住：原因与可复制修改指令

## 结论与证据范围

已在当前代码中复现“异常恢复把球变成规则小圆，随后每帧再次恢复并清零速度”的循环。它可以导致用户截图中那种球失去软体变化、似乎被锁住的现象。

截图中是 4096 球；本轮针对 4096 做了隔离复现，同时在完全合法的固定种子连射中复现了 256 球的同类循环。截图不能还原异常前的完整球堆，因此**没有确认截图那一局第一次触发恢复的具体碰撞**。该边界不影响下面已验证的恢复循环根因。

## 一、根因：保护函数产生了新的不合法形状

`www/js/physics.js:151` 的 `fixShape()` 做了三件事：

1. 将所有膜点重排到半径 `innerR * 0.5` 的规则圆上。
2. 将全部膜点速度清零。
3. 将内部质量球移回中心并清零速度。

面积由此缩至正常内面积的约四分之一。与此同时，`_collide()`（约第 494 行）只排除紧邻的两个同球膜点，其他同球膜点仍然碰撞；膜点半径为 12，接触距离为 24。

对 4096 球，膜点数为 49。半径减半后，隔一个点的两个膜点距离只有 **15.956**，明显小于 **24**，因此重建后的规则圆本身就有大量同球膜点互相穿透。

其几何关系为：隔一个点的弦长 `2 * r * sin(2π / n)`。恢复候选形状不能只检查“是正圆、坐标有限”，还要满足实际自碰撞约束。

碰撞位置投影再经 `_settle()` 按位移/子步时长反推速度，使该隔离场景的膜点速度达到约 **2832.38**，超过 `blownUp()` 的 **2000** 阈值。随后 `World.step()` 第 335 行再次调用 `fixShape()`，形成：

```text
触发一次保护
  → 半径减半、速度归零
  → 自碰撞深度穿透
  → 位置解碰后反推出异常速度
  → 再次触发保护
  → 每个物理帧结束时又是同一个小圆、零速度
```

这不是 `frozen=true` 导致的冻结：本轮复现中该字段始终为 false。正常连射里球心仍可能缓慢移动，所以更准确地说是“轮廓与速度被反复重置”，不是证明球心在任何情况下都绝对不动。

## 二、为什么重新合并有时能恢复

`World.merge()`（约第 710～736 行）会创建新的 `Sobo`，按两个旧球的轮廓重新采样，然后移除旧对象。新对象有新的轮廓、节点数及状态，因此可能脱离原先的重复重建循环。这与用户观察相符，但不是保证每次合并都能解除，也不是正式修复办法。

还要检查 `_overlaps()` 第 617 行：穿透恢复超过 3 秒也会对两个球调用 `fixShape()`，能够进入相同的坏恢复路径。本轮合法连射中记录到的循环由 `blownUp()` 触发，不能把它归因于超时分支。

## 三、为什么现有测试错误地显示通过

`tests/node/shape-recovery.js:46-50` 用日志相邻的两条事件判断连续帧。但日志可能是：

```text
帧 100：球 A 重建，球 B 重建
帧 101：球 A 重建，球 B 重建
帧 102：球 A 重建，球 B 重建
```

相邻日志的 ID 总是不同，于是旧统计将 A、B 各连续 3 帧误算为“最长 1 帧”。此外，该测试只测步后速度，而 fixShape 已经把超速清零，不能据此断言过程中没有超速。

本轮实测：

| 场景 | 结果 |
| --- | --- |
| 4096 单球、无墙、无其他球、关闭重力，主动恢复一次后推进 300 帧 | 额外重建 300 次，最长连续 300 帧；最终面积比 0.249315，速度 0，frozen=false |
| 同一隔离场景，只在内存把恢复半径从 0.5 改为 1 | 额外重建 0 次，300 帧后面积比 0.999213 |
| 同一隔离场景，只在内存跳过全部同球碰撞 | 每帧循环消失，但仍发生 27 次面积过冲重建；不是合格修复 |
| 现有测试同样的 seed=2、2500 帧上限、合法指针连射 | 在进入结束状态前共 741 次重建；一个 256 球在帧 1633～1964 连续重建 332 帧，一个 2 球连续 331 帧 |
| 原 `shape-recovery.js` | 退出码 0；把 seed2 的最长连续重建报告为 1 |

合法连射中，第一个循环球触发前面积比 **1.084568**、最大膜点速度 **2243.08**；重建后面积比骤降到 **0.248049**、速度清零。这次最初触发是膜点超速，不是旧版已经去掉的“单条边略长”条件。

“半径改为 1”的实验只证明隔离场景中错误恢复几何的因果作用，**不能直接作为密集堆积中的最终补丁**：恢复成完整圆可能侵入邻球或墙壁，还需接触约束和状态一致性验证。
